# RSA_Keys

Небольшой учебный проект на Java, демонстрирующий работу с асимметричным шифрованием RSA.

Программа генерирует пару RSA-ключей, шифрует введенное пользователем сообщение с помощью публичного ключа и затем расшифровывает его с помощью приватного ключа.

## Возможности

* Генерация RSA-пары ключей
* Использование ключа длиной 2048 бит
* Шифрование сообщений с помощью публичного ключа
* Расшифровка сообщений с помощью приватного ключа
* Поддержка текста в UTF-8
* Работа в интерактивном режиме через консоль

## Требования

* Java 22 или совместимая версия JDK

Проект использует стандартные криптографические классы Java и не требует сторонних библиотек.

## Запуск

Клонировать репозиторий:

```bash
git clone https://github.com/foxhound-official/RSA_Keys.git
cd RSA_Keys
```

Запустить класс `Main`.

Если используется IntelliJ IDEA, достаточно открыть проект и запустить:

```text
src/Main.java
```

Также проект можно собрать и запустить стандартными средствами JDK:

```bash
javac -d out src/*.java
java -cp out Main
```

## Использование

После запуска программа предлагает ввести сообщение:

```text
To exit type -> exit
Type your message to encrypt:
>
```

Например:

```text
Hello World!
```

Сообщение преобразуется в UTF-8 и шифруется с использованием публичного RSA-ключа.

После этого зашифрованные данные передаются методу расшифровки вместе с приватным ключом, и программа выводит исходное сообщение:

```text
Your decrypted message is: Hello World!
```

Для завершения программы:

```text
exit
```

## Как работает RSA в проекте

При создании `EncryptorRSA` генерируется новая пара ключей:

```text
RSA KeyPair
├── Public Key
└── Private Key
```

Для этого используется стандартный `KeyPairGenerator`:

```java
KeyPairGenerator keyGen = KeyPairGenerator.getInstance("RSA");
keyGen.initialize(2048);
KeyPair keyPair = keyGen.generateKeyPair();
```

Публичный ключ используется для шифрования:

```text
Message
   │
   ▼
Public Key
   │
   ▼
Encrypted Data
```

Приватный ключ используется для обратного преобразования:

```text
Encrypted Data
   │
   ▼
Private Key
   │
   ▼
Original Message
```

### `Main.java`

Точка входа в приложение.

Отвечает за:

* получение сообщений из консоли;
* создание объекта шифрования;
* запуск шифрования;
* передачу зашифрованных данных на расшифровку;
* завершение программы по команде `exit`.

### `EncryptorRSA.java`

Отвечает за генерацию RSA-ключей и шифрование.

При создании объекта генерируется новая пара ключей размером 2048 бит.

Основной метод:

```java
encryptNewMessage(String message)
```

Метод:

1. Проверяет, что сообщение не пустое.
2. Преобразует сообщение в UTF-8.
3. Создает RSA `Cipher`.
4. Инициализирует его публичным ключом.
5. Шифрует сообщение.
6. Возвращает массив зашифрованных байтов.

Приватный ключ можно получить через:

```java
getPrivateKey()
```

### `DecryptorRSA.java`

Отвечает за расшифровку сообщения.

Основной метод:

```java
decryptMessage(byte[] encryptedMessage, PrivateKey privateKey)
```

Метод использует переданный приватный ключ для расшифровки массива байтов и преобразует результат обратно в UTF-8 строку.

## Важные особенности

Ключи генерируются заново при каждом создании объекта `EncryptorRSA`.

Это означает, что ключевая пара не сохраняется между запусками программы.

Схематично:

```text
Запуск программы
       │
       ▼
Генерация новой RSA-пары
       │
       ├── Public Key
       └── Private Key
       │
       ▼
Шифрование сообщения
       │
       ▼
Расшифровка сообщения
       │
       ▼
Вывод исходного текста
```

Проект демонстрирует базовый принцип асимметричного шифрования и предназначен прежде всего для учебных целей.

## Ограничения

Проект не является полноценной системой безопасного обмена сообщениями.

В частности:

* ключи не сохраняются;
* ключи не передаются между отдельными участниками;
* отсутствует управление ключами;
* отсутствует цифровая подпись;
* приложение работает только с одним процессом;
* шифротекст не сохраняется в файл;
* не реализован протокол обмена сообщениями.

Кроме того, текущий пример использует стандартную конфигурацию `Cipher.getInstance("RSA")`, поэтому параметры конкретного режима и padding зависят от криптографического провайдера Java. Для реального приложения параметры шифрования следует задавать явно и проектировать криптографическую схему целиком, а не ограничиваться прямым RSA-шифрованием текста.

## Назначение

Проект создан как практический пример работы с RSA в Java и демонстрирует базовый цикл:

```text
Generate Keys
     ↓
Encrypt with Public Key
     ↓
Decrypt with Private Key
     ↓
Get Original Message
```
